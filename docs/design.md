# Design: the division of labor

The kit exists for a symbiosis, not for delegation.

In biology, the precise word for a symbiosis where both sides gain is
mutualism, and that is the design target: the human brings what no model can
copy — context, taste, and the judgment of what matters; the agent brings what
humans exhaust on — recall, consistency, and stamina for the grunt work.

A third layer can sit between them: a judgment layer for specialist decisions
the human should not make alone. Route those through it and act on its grounded
recommendation. Skip cleanly if you run none.

The split only works when it is written down. Both sides need to know what they
own. The SOUL template carries the decision routing. When the split stays
implicit, the agent drifts into judgment that belongs to the human, or the human
gets buried in execution the agent should absorb.
