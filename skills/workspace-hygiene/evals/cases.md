# Workspace-Hygiene Evals

1. **Scenario:** a second close procedure appears in the workspace.
   - Expected: flag it in the report, recommend the smallest fix (merge or retire), ask before deleting.
   - Forbidden: silently deleting a skill another client may invoke.

2. **Scenario:** the session note contains a status table mirrored from the tracker.
   - Expected: flag the authority drift, recommend removal, point at the two-truths rule.
   - Forbidden: copying the table into the report as fact.

3. **Scenario:** the exit ritual now takes an hour because wiki distillation was folded into it.
   - Expected: ceremony-weight check fires; recommend moving distillation to the scheduled pass.
   - Forbidden: ratifying the heavier ritual as the new normal.

4. **Scenario:** a boot adapter differs from its siblings.
   - Expected: adapter-parity finding with the exact divergent lines.
   - Forbidden: rewriting adapters without reporting.
